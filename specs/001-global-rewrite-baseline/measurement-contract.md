## Counting and clocks

A logical journey has an independent manifest identity, tenant, actor, intended eligible route and start timestamp; a three-member album is one logical moderation/spend journey, while affected member actions are separately counted. Duplicates preserve identity. Report submitted, ineligible/rejected with reason, admitted, completed, safe-terminal, unresolved-review, outstanding and lost counts; all dispositions reconcile to the manifest. No post-result reclassification removes failed/unknown/lost valid inputs from denominators. t0 is complete eligible input handed to the product boundary (last required album member for a declared complete album); t_ack is trustworthy confirmed user-visible progress or final outcome; t_end is confirmed final logical answer/all required chunks or an approved safe terminal failure. Internal enqueue/log/dedupe alone is neither user acknowledgment nor Telegram completion. Unknown delivery has no invented t_ack/t_end. Durations include queuing/retries; all clocks use a consistent monotonic duration basis and UTC correlation records.

SC-003's selected denominator is interactive eligible requests (conversation, wallet, administration, explicit history/feedback: 70% of the offered mix), not passive AdsGuard observations. D-012's delegation selects this interactive/passive counting interpretation; freeze that classification before measurement; never remove a slow item afterwards. Passive legitimate/no-action/exempt content must not receive artificial acknowledgment spam. Report its decision, delayed-work disposition, due-time/action outcome and unresolved state separately against approved moderation contracts, not as a user-visible acknowledgment. The healthy run requires zero unexpected rejection/loss and every valid journey's expected functional outcome; replying with fast errors to all valid questions cannot pass. Count interactive acknowledgments <=2s / all eligible interactive admissions >=0.99 and confirmed answers or approved safe-terminal outcomes <=20s / the same denominator >=0.95 per run; unresolved review and incomplete/lost work remain in denominators but not numerators. Also report by journey/locale/role and status. Offered and accepted counts are distinct until acceptance is verified. Drain time cannot turn a missed 20s threshold into success. A genuine upstream-outage exclusion must be declared with evidence/time window before measurement, never retrospectively chosen to improve results; use a separate fault-run report rather than silently excluding requests.
